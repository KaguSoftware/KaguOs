05HOW TO ACTUALLY LEARN THIS

Watching AI tips builds zero skill. Retention comes from doing — using each technique on your own real task the same day you learn it. Every rule below keeps you in the doing.

70 / 30
Use it live

Spend 70% of your time in an actual Claude window trying things, 30% watching or reading.

1 AT A TIME
One technique a day

Take a single technique, use it on a real task today, feel the difference, then add the next.

STEAL IT
Steal the prompt

When a video shows a prompt, pause and run your own version immediately. Muscle memory beats notes.

VERIFY
Trust, then verify

Every important answer gets one check. Assume "confident" ≠ "correct" until you've looked.

JOURNAL
Keep a prompt journal

Save the prompts that worked. Your best asset is a personal library of what gets good answers.

SHIP IT
Ship the capstone

Theory without a finished task is tutorial hell. Build the real thing by day 12.
